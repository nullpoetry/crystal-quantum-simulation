# Crystal Quantum Simulation

An interactive quantum crystal simulation featuring specialized technologies for quantum physics visualization and sound synthesis.

## Features

- **3D Crystal Visualization**: Utilizing OrbitXniner.js for quantum state rendering in three-dimensional space
- **Quantum Binary Tree**: WLQuantumBTree implementation for quantum state representation
- **Tree Vortex Particles**: Dynamic particle system with vortex physics and branch generation
- **Bytebeat MIDI Controller**: Audio synthesis using mathematical bytebeat functions
- **AI Entity Helper Widget**: Interactive assistance for quantum simulation understanding

## Getting Started

1. Clone this repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the application:
   ```
   npm run dev
   ```

## Technology Stack

- React frontend with Three.js for 3D visualization
- Express backend
- MongoDB for persistent data storage (optional)
- Custom audio synthesis engine
